Image Auto Generation
Replace mode swaps each <pic> tag for a markdown image inside the same AI message. Insert mode adds images as message media. New message uses SillyTavern image generation's normal separate message behavior. Disabled turns detection off.
Prompt injection tells the AI to write <pic prompt="..." type="..."> tags. Keep it off if your preset, character, or Megumin already emits pic tags.
This text is inserted into the model prompt when Prompt Injection is enabled. It should explain when to emit <pic> tags and which type names are allowed.
This finds image tags in AI messages. Capture group 1 must be the image prompt. The default matches single quotes, double quotes, multiline prompts, and self-closing tags.
Position chooses the role used for injected instructions. System is usually strongest. User or assistant can be used if a model reacts poorly to extra system text.
Depth controls where the injected prompt is placed in the model input. 0 means near the end, which is easiest and usually best.
Used when the AI writes a <pic> tag without a valid type. Portrait is good for characters, scene is good for wider action.
How many images may generate at the same time. 1 is safest for ComfyUI and avoids model unload/reload thrashing. Higher can be faster but heavier.
Wait this long after the AI message completes before the final image insert/replace pass. 0 is normal.
Off means generation can start as soon as a complete <pic> tag appears while the AI is streaming. On waits until the full message is done.
Enables extra browser console logs for troubleshooting. Leave off for normal use.
Width and height control image shape and VRAM use. Higher pixel counts are slower and heavier. Red pixel counts are above the recommended budget but still allowed.
